An MCP server that gives AI agents semantic recall over an email archive. Every thread is LLM-tagged on sync; agents search by what you actually remember (“the invoice from the roofing guy, sometime last spring”), not exact keywords.

Scribe

Drafts replies to incoming business email, grounded in the business’s own website content. It answers what the site actually covers and says so when it doesn’t know, instead of inventing. A human reviews every send.

More projects

Code to read, with the design notes in each README.

  • catalog — search your own email by whatever you remember about it: mailbox sync, attachment text extraction, LLM tagging, and an agentic search loop on top.
  • ElasticWebServiceAWS — auto-scaling web service on AWS: ALB, ASG with target tracking on request count, health checks, and scale-in with connection draining.
  • PuzzleSolver — C++ backtracking solver for a 10×10 piece-placement puzzle, with a thread-pool version that scales near-linearly with cores, plus benchmarking.
  • BasicThreadPool — a C-style POSIX thread pool from scratch; the groundwork for PuzzleSolver’s multithreading.
  • ColourDetectionMLProject — a PyTorch CNN image classifier built on the ImageFolder structure, easy to retrain on your own classes.
